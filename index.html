选择密钥对文件
可多选：私钥 + 公钥(.pub)，或直接选择 ZIP 密钥包 · 私钥保存在本地记录

可同时选择私钥与公钥(.pub)，也可只选私钥或一个 ZIP 密钥包；导入时会校验配对并生成 VPS 导入命令。仅支持未加密的 OpenSSH Ed25519 与 RSA PKCS#1/PKCS#8 私钥；带密码私钥请先在本地终端转换。

    暂无记录。生成或导入密钥后，公钥会以本地记录形式保存。

    记录保存在本机浏览器中：公钥与私钥都会保存，可随时载入完整密钥对。请勿在公用设备上使用；清除浏览器数据或点下方「清空」即可彻底删除。

    使用命令

    一键复制
    local — 一键安装公钥并验证登录（把 用户@服务器 换成你的）
    ▼ 自动填密码（输入后命令自动带上，直接复制即可）

    输入后上方命令会变成 sshpass -p '密码' …。需本机装有 sshpass（iSH 终端执行 apk add sshpass 安装）。密码会进入剪贴板和终端历史，用完请及时清除输入框。

    ▼ 备选：在已登录的服务器终端里只安装公钥
    vps — 仅安装公钥到 authorized_keys

    下载的私钥文件请执行 chmod 600 文件名 后再用于 ssh -i。一键命令需本机装有 ssh-copy-id（macOS/Linux/iSH 都有）。
